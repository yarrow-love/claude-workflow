# Phase 1 — probes: the decisive experiment battery

## Chore Objective

> executor@play/2cb889b5-b570-4b6d-b435-c315de40e68d

Establish the ground truth phase 2's doctrine rests on: a battery of falsifiable probes of the return-path topology, run on the pinned CLI through a probe-parent session that **is** the root observer (R2). Every verdict is behavior-based, quoted verbatim, and reproducible from its recipe. Spec: [`work/milestones/2.return-path/1.probes.md`](../../milestones/2.return-path/1.probes.md); milestone: [`MILESTONE.md`](../../milestones/2.return-path/MILESTONE.md); seeding evidence: [the filing](../bugs/26-07-25.bug.orchestration-return-path.md) and [the proposal](../../proposals/26-07-25.return-path.md).

**The hypothesis under test — H′, the liveness hypothesis.** The filing's original one-sentence theory was *"control descends edge by edge; every asynchronous return below the root collapses to the root."* Reconnaissance found that formulation overreaches its own evidence: every collapse in the filing's eight instances involved a dispatcher that **had stopped** (a turn ended mid-dispatch, or a continuation of a completed agent), while the M1 corpus contains a depth-1 dispatcher that stayed alive and *did* receive its background children's completions. The milestone architect ruled the refinement in (consult, 26-07-26) and restated the hypothesis this battery tests:

> **H′** — an asynchronous result is delivered to the dispatcher's own loop **if that loop is still live** when the result arrives; if the dispatcher has stopped, the result falls through to the nearest live loop above (observed: the root); and **no path exists for a stopped dispatcher to receive it afterward.**

The battery's job is to confirm, refine, or falsify H′ on the pinned CLI — and to exercise the idiom phase 2 would sanction, so that doctrine is never landed on an untested mechanism.

**What this phase does not do.** It does not design doctrine (R1 — phase 2, after `/plan`, with these verdicts as its only admissible evidence). It does not settle the reserved outcome (R4 — that escalates to the operator). It touches no canon (R3).

## Standing rules for the probe parent

   Never read a whole transcript into context; grep and quote.
6. **Count the downward channel.** Ledger row 3 (downward addressing is reliable) has no probe of its own — it is settled by tally. Every root→subagent SendMessage in the battery is a trial: record each one's outcome (delivered / not delivered) and report the count in the reconciliation.

9. **Ordering.** Run P0 → P1-a → P1-b → P2-a → P2-b → P2-c → P3 → P4 → P5 → P6, in that order. P4 resumes completed agents, which re-fires notifications for the same task-id — running it late keeps that noise out of earlier probes' evidence.

11. **Do not interpret into doctrine.** Verdicts only. Phase 2 designs; you measure. If you find something the battery does not cover, write it under § Unprobed observations — do not chase it.

### P1-a — background dispatch, dispatcher stops *(the central claim, as chartered)*

Dispatch `subagent_type: researcher`, `run_in_background: false` (you collect this manager synchronously; the *manager's* child is the background one), `description: "probe-manager-1a"`, prompt:

> Dispatch a child agent with `run_in_background: true` and the prompt 'Reply with exactly: MARKER-P1A-CHILD'. Then record, verbatim: **(a)** the manager's return and its captured `agentId`; **(b)** where the child's completion surfaces — a task-notification in your own root context (quote the whole block, including any `<output-file>` path and `<summary>`), your transcript, the manager's transcript, or nowhere; **(c)** after the child completes, SendMessage the manager by id: *"Did you ever receive your child's result? ### P1-b — background dispatch, dispatcher stays alive *(the arm that separates the variables)*

Same dispatch shape, `description: "probe-manager-1b"`, prompt:

> Dispatch a child agent with `run_in_background: true` and the prompt 'Reply with exactly: MARKER-P1B-CHILD'. Then **stay alive**: do not end your turn.
