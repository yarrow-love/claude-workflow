## Reconnaissance

> executor@play/c1378142-cf5c-4ad2-97b0-920533f97a7c

Two researcher subagents (one per phase, read-only, parallel). The pass earned its keep: it found four substantive defects in phase docs written an hour earlier in this same session, which is the argument for the gate existing at all — a plan's author is its worst auditor.

### Defects in the plan as written

**P2-1 — The validity check destroys the cold state it precedes.** Phase 2 orders its TTL validity check "first and blocking," before cell (a). But the check's confirmatory turn is itself a touch on the vehicle prefix — exactly what cell (a) requires untouched. As written, cell (a) inherits whatever warmth the check just left. The doc's own "cold cells are destroyed by any prior touch" discipline was not applied to its own check.

**P2-2 — A direct TTL measurement exists and the doc specified a slow proxy.** Cache-write tokens ride a **nested** `usage.cache_creation` object carrying `ephemeral_5m_input_tokens` / `ephemeral_1h_input_tokens`, not only the flat `cache_creation_input_tokens` scalar. The nested field reports *which TTL a write claimed* on the very first write — no idle wait at all. The doc's warm-then-idle-then-reread check is a slower, indirect proxy for a fact one field answers directly. This also means the flat scalar alone is insufficient for criterion 1.

**P2-3 — `--model` is not one of "the five layers."** `.claude/bin/consult` defaults to `--model fable` as a *separate* flag from the five read-only layers. Phase 2 instructs "consult's five read-only layers reproduced verbatim" — a builder following that literally leaves the model unpinned, so fork cells and the channel could run different models. Since the prompt cache keys on the **byte-exact** prefix and tool/system-prompt content varies with model, an unpinned model silently makes the matrix compare different prefixes while believing it measures one. Close to self-contradicting as written.

**P2-4 — "Same question, every cell" contradicts cell (e).** The matrix intro fixes one question for all six cells; the table specifies a trivial prompt for the heartbeat. Both cannot be followed.

### Risks and hazards

**Ambient TTL is auth-dependent, and phase 1 never forces it.** Subscription/OAuth auth defaults to a 5-minute TTL, API-key auth to 1 hour; this environment shows no `ANTHROPIC_API_KEY`, so 5m is *likely* ambient but unverified. Load-bearing consequence: the idle gap that opens phase 2 must clear the TTL **phase 1's own touches used**, and phase 1 sets no forcing variable. If ambient were 1h, a 6-minute gap silently under-cools the vehicle and reports a warm cell as cold — corrupting the baseline every other ratio is computed against.

**Bun `spawn` holding stdin open — three concrete pitfalls, no in-repo precedent** (all four existing `.claude/bin/` scripts are `spawnSync`): `.write()` buffers internally and needs an explicit `.flush()` per turn or turn N+1 silently never arrives; `proc.kill()` does not close pipes, so EOF must come from `proc.stdin.end()` (reaching for `.kill()` muddies the clean-exit evidence criterion 6 wants); and stdout **and stderr** must be drained concurrently with the exit promise or the OS pipe buffer deadlocks — phase 1 mandates teeing stdout and says nothing about stderr, which `--verbose` plus per-turn cosmetic tool warnings will fill.

**`commit-guard` could block a headless child's exit.** The repo wires `SessionEnd → session-archive` and `Stop → commit-guard`. `disableAllHooks: true` should prevent both, and `session-archive`'s archive-on-stamp gate is a second net — but if `disableAllHooks` failed, a `Stop` hook returning `{"decision":"block"}` could hang the child rather than let it exit on EOF, hitting criterion 6 directly. Neither phase asks for an explicit "no hook artifacts appeared" check.

**Vehicle auto-selection is an unguarded mutation vector.** Phase 1 requires excluding "the running session's own" transcript when picking the largest — but no documented mechanism exposes a session's own id to a script it invokes. A buggy or unimplemented exclusion could in principle fork the hosting session's live transcript. Moot by luck this run (the hosting session is ~10× smaller than the vehicle), but that margin is incidental, not guaranteed.

**Concurrent use can silently destroy a cold cell.** This repo is in active use across many sessions; any other session running a consult or fork against the same vehicle during a required idle window destroys the cold measurement leaving no trace in the harness's own log.

**Idle gaps exceed a single tool call's ceiling.** Required waits (6+ minutes each, more if the TTL assumption is wrong) must be the harness's own internal async sleep — never a shell `sleep` the dispatching agent awaits, which is exactly the "turn that ends waiting ends the session with the work ownerless" failure the executor card warns about.

**b2's shared-prefix figure is inferred, not measured.** `usage` reports aggregate totals; it does not attribute which bytes of a hit came from which historical write. Worse, cache hits require *breakpoint alignment*, not merely prefix overlap — if the channel's breakpoint sits after its own first turn, a vehicle-only fork may get **zero** partial hit rather than a partial one. Criterion 5 must be read as requiring a declared inference.

**Unverified, flagged for check before trusting numbers:** a second-hand claim that `stream-json` usage can report cache-token counts inflated 3–8× on responses with multiple content blocks. Not confirmed against a primary source; if real and non-uniform across cells, it corrupts ratios.
